Quality / Statistical process control

SPC & Process Capability Dashboard

A manufacturing test-bench analysis that brings control charts, capability, Pareto analysis, and FMEA into one dashboard.

Working dashboard
PythonSPCDMAICStreamlit

The engineering problem

Test-bench cycle time can become a production constraint and a quality signal. This portfolio study uses the public Mercedes-Benz Greener Manufacturing dataset to investigate stability, variation, and configuration-level differences.

The approach

  1. Define the quality characteristic

    Treat test-bench duration as a critical-to-quality variable and make the study's specification window and target explicit.

  2. Check stability

    Compare I-MR, subgroup, EWMA, and CUSUM views with Western Electric and Nelson run-rule detection.

  3. Study capability and distribution

    Review capability indicators alongside the measured distribution. The repository identifies non-normality, so normal-model capability estimates need careful interpretation.

  4. Prioritize investigation

    Use configuration-level Pareto analysis, a structured fishbone, and FMEA to focus follow-up engineering work.

What the project delivers

The dashboard makes process excursions and configuration differences visible and documents the Define, Measure, and Analyze phases of DMAIC. Improvement pilots and sustained control validation remain future work.

Data & interpretation

This is an independent study of a public competition dataset, not work performed for Mercedes-Benz. The specification window is an analytical assumption. Proposed corrective actions have not been validated in a production pilot.

The next engineering step

Design a focused experiment, validate proposed countermeasures, and document an operational control plan.
