Semiconductor Defect Analysis

A machine learning workflow and interactive dashboard for classifying wafer defects from process and inspection data.

Working prototype
Pythonscikit-learnStreamlit

The engineering problem

Early defect detection can help engineers investigate process excursions and protect wafer yield. This project examines whether process and inspection measurements can distinguish normal wafers from scratches, particles, edge-ring issues, and contamination.

The approach

  1. Prepare wafer features

    Combine numeric process measurements and categorical wafer information in a reproducible preprocessing pipeline.

  2. Train a baseline classifier

    Use a Random Forest model to classify defect types from the included synthetic sample dataset.

  3. Evaluate beyond accuracy

    Review holdout precision, recall, macro F1, a confusion matrix, and stratified cross-validation to understand class-specific performance.

  4. Make the analysis accessible

    Use a Streamlit dashboard to inspect the data, train the model, review feature importance, and explore single-wafer predictions.

What the project delivers

The repository contains the preprocessing, training, evaluation, and prediction workflow, along with a deployed dashboard. Performance metrics are generated when the model is trained; no production yield improvement is claimed.

Data & interpretation

The included wafer data is synthetic. Feature importance is a model diagnostic and does not establish process causation. Production use would require real inspection data, validation across lots, and drift monitoring.

The next engineering step

Validate on real process data, compare model tuning strategies, and connect defect predictions to a wafer-yield investigation.
